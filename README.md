# NutriTrack V22

NutriTrack V22 – Android/PWA versie.

Bevat de verbeterde fullscreen barcode scanner, slimme invoer, productdatabase, favorieten, vaste maaltijden, boodschappenlijst en voedingscoach.

Voor GitHub Pages: upload/overschrijf alle bestanden uit deze map. Laat `index.html`, `manifest.json`, `service-worker.js`, `icon-192.png` en `icon-512.png` in dezelfde hoofdmap staan.
